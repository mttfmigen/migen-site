## LA SITUATION

Pour un fournisseur de rang 1, ces deux échecs remontent jusqu'au constructeur.

Les objectifs posés :

- Faire tenir le préventif sur un parc d'équipements variés.
- Maintenir des technologies très différentes : injection, laser, robotique, automatismes.
- Réduire les arrêts non planifiés sur les presses à injecter.
- Disposer de techniciens polyvalents sur toutes ces technologies.
